## 报错弹层文案接入多语言
项目本地化：`backend.Language`，主语言包 `assets/languages/{en_us, zh_cn, zh_tw}.json`，默认 `ClientPrefs.data.language = 'zh_cn'`。

- `source/debug/CrashOverlay.hx` 新增 `tr(key, fallback, ?params)`：调 `Language.getWithFallback(key, fallback, params)`，优先级 **模组 `.lang` > 当前语言 JSON > 内置中文兜底**，整段 try/catch；兜底路径由 `applyParams()` 自行替换 `{0}` / `{$0}`。
  **关键理由**：崩溃可能发生在 `Language.load()` 之前或语言包加载失败，此时 `Language.get` 会返回裸 key，必须有内置兜底（默认语言是 zh_cn，故兜底用简体中文）。
- 8 个 key：`crash_overlay_title / hint / count_saved / count_repeat({0}) / tech_details / btn_continue / btn_title / btn_restart`，已写入三个主语言 JSON（英文 / 简体 / 繁体）。次数用 JSON 的 `{0}` 占位（模组 `.lang` 体系用 `{1}` 起，各自内部处理）。
- `setHtml()` 现在对文案 `escapeHtml`（翻译含 `&` / `<` 不会破坏 htmlText）；`makeButton()` 去掉无用的 `label` 参数，按钮文字统一由 `buttonLabel()` → `tr()` 提供。
- **顺带修 bug**：`setCountOnly()` 原来只调用 `countText(count)` 却丢弃返回值 → 重复报错时次数永远不刷新；改为 `setHtml(_countTF, countText(count), ...)`。
- 布局：标题/说明高度在按屏宽给基础值之后，再用 `textHeight` 实测扩高（上限 `100*s` / `130*s`），因为英文说明明显长于中文，固定行高会被裁。字体仍用 unifont（覆盖中/英/繁），标题 32px、其余 16px 不变。
- 验证：三个 JSON `json.load` 通过且 8/8 key 齐全；三平台 js / cpp+sys / cpp+android 编译 EXIT=0（桩工程补 `backend/Language.hx` 桩）；`CrashOverlay.hx` / `CrashHandler.hx` / `Main.hx` 花括号平衡 0。

## 日志导出跟随 Android「存储位置」设置
用户反馈：移动端「导出」按钮没跟随当前设置项，Android 支持多种存储位置（Data / Media / Obb / External），需要自适应。
- **根因**：`GameLogDisplay.getLogDir()` 在移动端写死 `lime.system.System.applicationStorageDirectory`（应用私有目录），与项目统一的用户数据根目录无关。项目里 `CrashHandler.saveErrorMessage`、`Paths`、`Mods`、`StorageUtil` 都走 `StorageUtil.getExternalStorageDirectory()` —— 它按设置页的存储类型动态返回根目录，`setStorageType()` 会刷新 `_storageRoot` 缓存，内部还处理了「无所有文件访问权限」时回退到应用私有目录。
- **修法**：`getLogDir()` → `getLogRoot()`，返回规范化根目录（去掉结尾斜杠）：
  `#if android StorageUtil.getExternalStorageDirectory()` / `#elseif ios lime.system.System.documentsDirectory` / `#elseif sys Sys.getCwd()` / `#else ""`。
  `exportLogs()` **每次点击都重新取根目录**（不缓存，切换设置后立即生效），并**逐级创建** `<root>/logs` 与 `<root>/logs/output` —— 原代码 `createDirectory(".../logs/output/")` 只建一级，父目录 `logs` 不存在时会失败。
- 与崩溃日志共用同一个 `logs` 文件夹，桌面也统一到 `Sys.getCwd()`（原来用 `System.applicationDirectory`，可能与崩溃日志不在一处）。
- 验证：js / cpp+sys / cpp+android / **cpp+ios** 四个目标编译 EXIT=0（桩工程 `import.hx` 需导入 `mobile.backend.StorageUtil` 桩）；已确认 `lime.system.System.documentsDirectory` 在 lime 8.3.2 中存在。四个源码文件花括号平衡 0。
- 备注：日志窗口的按钮/状态文案仍是硬编码中文，未接入 `Language`（本轮未要求）。
