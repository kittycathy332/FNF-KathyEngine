## 🔧 Customization

To disable features like *Lua Scripts* or *Video Cutscenes*:

1. Open `Project.xml`
2. Locate target variables (e.g., `VIDEOS_ALLOWED`, `LUA_ALLOWED`)
3. **Delete line** or **comment it out** using XML syntax:\
   `<!-- YOUR_LINE_HERE -->`
